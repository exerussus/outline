# Exerussus Outline

Аутлайн для URP на Render Graph. Контур строится в экранном пространстве по полю расстояний (Jump Flood), а не раздуванием меша: нет разрывов на жёстких рёбрах, ширина от 1 до 256 px, затухание задаётся кривой.

## Возможности

- Внешний контур с кривой затухания, ширина в пикселях или в мировых единицах.
- Внутренний контур, заливка силуэта, rim (френель).
- Отдельный стиль для перекрытой части: скрыть, как видимую или с тинтом и бегущей штриховкой.
- Паттерны в экранном пространстве: полосы, точки, сетка, клетка, скан-линии, шум, соты.
- Анимация: пульс альфы и ширины, шум, плавное появление и исчезновение.
- Группы: объекты одной группы образуют общий силуэт. Между группами действует приоритет: свечение группы с большим приоритетом рисуется поверх силуэта соседней, цвета на стыке смешиваются.
- Альфа-клип и прозрачные материалы: текстура и порог берутся из материала (URP Lit/Unlit, `_MainTex`/`_Color`, glTFast).
- Совместим с GPU Resident Drawer.
- Отладочные виды и статистика кадра.

## Требования

- Unity 6000.6, URP 17.6 (Render Graph).
- Проверено на Windows, Direct3D 11. WebGL2 предусмотрен настройками, но не проверялся.
- Подсвечиваются только `MeshRenderer` и `SkinnedMeshRenderer`.
- Кадр не больше 4095 px по каждой стороне.

## Подключение

1. Добавить фичу в рендерер: меню **Exerussus → Outline → Подключить к рендерерам URP**. Команда добавляет `OutlineRendererFeature` во все Universal Renderer Data в `Assets`. Вручную: Universal Renderer Data → Add Renderer Feature → Exerussus Outline.
2. Создать стиль: **Create → Exerussus → Outline → Style**.
3. Включить подсветку кодом или компонентом `OutlineTarget`.

## Использование

```csharp
using Exerussus.Outline;

// показать
var handle = OutlineApi.Show(gameObject, style, OutlineOptions.InGroup(group: 1, fadeIn: 0.15f));

// изменить
handle.SetStyle(otherStyle);
handle.FadeTo(0.5f, 0.2f);

// убрать
handle.FadeOutAndHide(0.2f);
```

`OutlineTarget` — компонент для сцены: пока он включён, объект подсвечен. Работает и в редакторе.

### OutlineApi

| Член | Назначение |
|---|---|
| `Show(GameObject, style[, options])` | Подсветить рендереры объекта (по умолчанию вместе с детьми). |
| `Show(Renderer, style, options)` | Подсветить один рендерер. |
| `Show(IReadOnlyList<Renderer>, style, options)` | Подсветить набор рендереров. |
| `Hide(handle)`, `HideAll()` | Снять подсветку. |
| `SetStyle`, `SetGroup`, `SetPriority` | Изменить параметры живой подсветки. |
| `SetFade(handle, v)`, `FadeTo(handle, v, t)`, `FadeOutAndHide(handle, t)` | Непрозрачность и плавные переходы. |
| `IsAlive(handle)`, `HasAny`, `AliveCount` | Состояние. |
| `MaxEntries` | Лимит одновременных подсветок: 63. |

У `OutlineHandle` те же методы экземпляра. Хэндл версионный: после `Hide` его методы ничего не делают.

Если рендерер входит в несколько подсветок, рисуется последняя. После её снятия рисуется предыдущая.

### OutlineOptions

| Поле | Значение |
|---|---|
| `group` | Группа. Одна группа — общий силуэт. |
| `priority` | Добавка к приоритету стиля. |
| `alphaMode` | `Auto` — по материалу, `ForceClip` — всегда клипать по `alphaThreshold`, `Ignore` — силуэт по мешу. |
| `alphaThreshold` | Порог для `ForceClip`. |
| `includeChildren`, `includeInactive` | Сбор рендереров для `Show(GameObject)`. |
| `fadeIn` | Длительность появления, с. |

## Стиль (OutlineStyle)

Изменения в инспекторе применяются на лету.

| Группа | Поля |
|---|---|
| Внешний контур | `outerColor` (HDR), `widthMode` (Pixels / World), `outerWidth`, `outerCurve` (альфа от края, t = 0, до границы, t = 1) |
| Внутренний контур | `innerColor`, `innerWidth`, `innerCurve` |
| Заливка и rim | `fillColor`, `rimColor` (альфа — сила), `rimPower` |
| Смешение | `additive` (0 — альфа-смешение, 1 — сложение), `priority` |
| Перекрытая часть | `occludedMode` (Hidden / Same / Custom), `occludedTint`, `dashPeriod`, `dashDuty`, `dashSpeed`, `occludedInnerMultiplier` |
| Паттерн | `pattern`, `patternLayers` (Outer / Inner / Fill), `patternScale`, `patternAngle`, `patternSpeed`, `patternFill`, `patternStrength`, `patternSoftness` |
| Анимация | `pulseSpeed`, `pulseAlpha`, `pulseWidth`, `noiseScale`, `noiseAmount`, `noiseSpeed` |

Если кривая меняется из кода, после изменения нужно вызвать `style.MarkChanged()`.

## Настройки фичи (OutlineRendererFeature)

| Поле | По умолчанию | Значение |
|---|---|---|
| `passEvent` | BeforeRenderingPostProcessing | Когда композитить. До пост-обработки HDR-цвет попадает в Bloom. |
| `fieldScale` / `fieldScaleWebGL` | 1 / 0.5 | Разрешение поля расстояний относительно кадра. |
| `extraPass` / `extraPassWebGL` | вкл / выкл | Дополнительный проход JFA с шагом 1. |
| `maxWidth` | 256 | Предел ширины, px. |
| `scaleWithResolution`, `referenceHeight` | вкл, 1080 | Масштабировать ширины в px по высоте кадра. |
| `priorityScale` | 0.25 | Вес единицы приоритета на стыке групп. |
| `seamOverlay` | вкл | Свечение группы с приоритетом ≥ поверх силуэта соседней. |
| `seamBlend` | 6 | Радиус смешения цветов на стыке, px. 0 — резкая граница. |
| `cropToBounds` | вкл | Считать только в экранном прямоугольнике подсвеченного. |
| `scissor` | вкл | Отсекать растеризацию этим прямоугольником. |
| `autoFieldScale`, `gpuBudgetMs`, `minFieldScale` | выкл, 1.5, 0.375 | Экспериментально: подбор разрешения поля по GPU-времени. |
| `occlusionBias` | 0.02 | Допуск сравнения с глубиной сцены, м. |
| `transparentCutoff` | 0.1 | Порог альфы для прозрачных материалов в режиме `Auto`. |
| `debugView` | None | Mask / Seeds / Distance. |
| `renderInSceneView` | вкл | Рисовать в Scene View. |

`OutlineRendererFeature.Stats` возвращает статистику последнего кадра игровой камеры:
- число записей и вызовов отрисовки;
- размер и масштаб поля, долю кропа;
- число проходов JFA;
- время записи на CPU;
- время на GPU (на него нельзя полагаться, см. «Ограничения»).

## Как это работает

1. **Маска.** Подсвеченные рендереры рисуются по одному в RGBA8. В канал R пишется id записи, в G — rim, в B — видим ли пиксель относительно глубины сцены. Альфа-клип выполняет материал-двойник маски.
2. **Поле расстояний.** Сиды — граничные пиксели силуэта: у них есть соседний пиксель пустой или из другой группы. Координаты сидов хранятся в пикселях кадра, поэтому поле в пониженном разрешении даёт расстояния с точностью кадра. Внешнее поле взвешено по ширине и приоритету записи. Внутреннее поле считается только на последних шагах, на дальность внутреннего контура.
3. **Композит.** Кривые, заливка, rim, паттерны, перекрытие, анимация и смешение на стыке накладываются в цвет камеры. Выход premultiplied.

## Производительность

Замер на Intel UHD (i5-1035G1), Direct3D 11, в редакторе: кадр 1226×689, 17 подсветок, кроп — 20% кадра. В таблице — прирост времени кадра к выключенной фиче.

| Настройка | мс |
|---|---|
| поле ×1 | 5.4 |
| поле ×0.5 | 1.9 |
| поле ×0.25 | 1.5 |
| поле ×1 без кропа | 20.8 |
| поле ×1 без scissor | 7.5 |
| поле ×0.5, без JFA+1 и мягкого стыка | 1.8 |

Рекомендуется: кроп и scissor включены, поле ×0.5. На слабых GPU дополнительно выключить `extraPass`.

## Ограничения

- GPU-время из `ProfilingSampler` в редакторе недостоверно: бывают нули и залипшие значения. Поэтому `autoFieldScale` выключен по умолчанию. На WebGL GPU-время недоступно.
- Scissor опирается на то, что прямоугольник задаётся от нижнего края render texture. Если у края кадра свечение обрезается, выключите `scissor`.
- Паттерны только в экранном пространстве.
- Прозрачные объекты не пишут глубину, поэтому перекрытие ими не определяется.
- Не больше 63 подсветок одновременно. Кадр не больше 4095 px по стороне.

## Дорожная карта

1. Авто-разрешение поля по детерминированному бюджету (площадь поля × число проходов) вместо GPU-времени. Одинаково для всех платформ, включая WebGL.
2. Значения по умолчанию: поле ×0.5, без JFA+1.
3. Композит: проверку соседей для мягкого стыка делать только на реальных стыках. Обрабатывать только полосу, где есть свечение.
4. WebGL2: билд, замеры, отдельный пресет качества.
5. Сглаживание края силуэта: MSAA-маска или субпиксельные сиды.
6. Паттерны в пространстве объекта и мира.
7. Rendering Layers как второй источник подсветки для большого числа объектов.
8. Поддержка кадров больше 4095 px.
9. Бенчмарк: прирост к выключенной фиче прямо в логе, повтор замера без фичи, прогон в standalone-билде.
