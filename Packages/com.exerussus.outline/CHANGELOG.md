# Changelog

## Unreleased

- Плавная смена стиля живой подсветки: `handle.SetStyle(style, duration)`, `IsStyleBlending`. Смешиваются цвета, ширины, кривые, градиенты и параметры эффектов, в том числе переход в прозрачность и обратно; дискретные параметры переключаются на середине. Обратная смена посреди перехода продолжает его с той же точки.
- Координаты поверхности (`Surface*`) при сглаживании пишет отдельный проход без MSAA вместо второй цели MSAA-маски: на Intel UHD −0.7 мс. Пиксели края, центр которых не покрыт, берут координату соседа.
- `settings.surfaceDiag` — диагностика цены координат поверхности для бенчмарка (без чтения, без записи, прежний путь).
- `OutlineTarget`: поле `layer` и плавная смена стиля через свойство `Style` (`styleTransition`).

## 0.4.0

- Слои подсветки: `OutlineOptions.layer` 0–3, `InLayer(...)`. Каждый непустой слой — свои маска, поле и композит, слои накладываются по порядку; владение рендерером — внутри слоя. `OutlineStats.Layers`.
- `OutlineFx`: пульс и вспышка — в слое 1 поверх подсветки объекта; растворение — в верхнем слое и гасит подсветки объекта в остальных слоях.
- Слой, в котором ни у одной записи нет внешнего и внутреннего контура (заливка, вспышка, растворение), не считает поле расстояний. Встроенная вспышка `OutlineFx.Flash` — только заливка.
- Паттерны на поверхности: цель позиций — RG16F с готовой координатой развёртки вместо RGBA16F (вдвое меньше памяти). Сканер в `Surface*` работает в плоскости развёртки: y — высота на боковых гранях.
- Временные эффекты `OutlineFx`: `DissolveOut` (растворение, после — объект скрыт), `DissolveIn` (проявление из растворённого, после — эффект снят), `Pulse` (одна вспышка подсветки), `Flash` (засветка объекта), `Restore`, `IsDissolved`; колбэк `onComplete`.
- Растворение в режиме прозрачности режет сам объект: на растворённых участках виден фон, по кромке — свечение.
- Исправлено: «стекло» (`objectOpacity` > 0) не рисовало сам объект при GPU Resident Drawer.
- Прозрачность: сам объект рисуется материалом-двойником маски с упрощённым освещением (основной свет + окружение по текстуре и цвету материала) — работает с GPU Resident Drawer. Прежний путь через исходный материал — `objectColor = SourceMaterial`.
- Очистка целей маски только в прямоугольнике работы; быстрый путь резолва MSAA; кроп по повёрнутым локальным bounds у `MeshRenderer`.

## 0.3.0

### Качество
- Сглаживание края силуэта: маска рисуется в MSAA-цель (`edgeAntialiasing`, по умолчанию ×4, WebGL — выкл.), резолв даёт покрытие пикселя. Край свечения, внутреннего контура и заливки — с субпиксельной точностью.
- Поле ниже ×1: у края расстояние уточняется по соседним сидам, лучшая запись выбирается для точки кадра среди соседей 3×3. Тонкие контуры не рассыпаются в точки, узкое свечение соседа не пробивает дыры в широком.
- Стык групп: свечение группы с меньшим приоритетом гаснет вглубь чужого силуэта на радиусе `seamBlend`, а не обрывается.

### Паттерны и текстуры
- Пространство паттерна `patternSpace`: `Screen`, `Object` (привязка к центру объекта, период в мировых единицах), `SurfaceObject`, `SurfaceWorld` (паттерн на поверхности). Период — `patternWorldScale`.
- Свои текстуры: `pattern = Texture` с `patternTexture`, текстура заливки `fillTexture`.

### Эффекты
- Свечение: градиент цвета по ширине (`outerGradient`) и по контуру (`contourGradient`), волны, бег по контуру, огонь, электричество, искры.
- Заливка: сканер, растворение (в том числе по fade).
- Прозрачность и маскировка (`seeThrough`): объект скрывается из основного прохода камеры (тень сохраняется), на его месте — фон с искажением и преломлением у края, мерцание края, тинт, переход по fade.

### API и прочее
- `OutlineStats.EdgeSamples`, отладочный вид `ObjectColor`.
- Таблица данных записей расширена до 32 столбцов.

### Обновление
- Новый шейдер `Hidden/Exerussus/Outline/Resolve`: выполните **Exerussus → Outline → Подключить к рендерерам URP**, чтобы ссылка на него попала в билд.

### Известные проблемы
- `objectOpacity` > 0 (полупрозрачный объект, «стекло») при включённом GPU Resident Drawer не рисует сам объект — виден только фон с тинтом. Маскировка (`objectOpacity = 0`) работает.

## 0.2.0

- По умолчанию выключен дополнительный проход JFA.

- `OutlineStats`: стоимость и бюджет поля вместо GPU-времени.
- EditMode-тесты: `OutlineApi`, `OutlineQuality`.
