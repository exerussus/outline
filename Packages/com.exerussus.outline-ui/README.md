# Exerussus Outline UI

Подсветка элементов UI Toolkit своими стилями `OutlineUiStyle` (тот же набор эффектов, что у подсветки мира `com.exerussus.outline`, в пунктах UI). Контур строится по реальной альфе содержимого: текст, картинки с прозрачностью, скругления, бордеры, дочерние элементы — без ручных масок.

## Требования

- Unity 6000.6 (фильтры UI Toolkit: `FilterFunctionDefinition`, `style.filter`).
- `com.exerussus.outline` 0.4.0 — общие перечисления паттернов, кривые по умолчанию и часы.

## Использование

```csharp
using Exerussus.Outline.UI;

// подсветить элемент (вместе с детьми)
var h = OutlineUi.Show(button, style, OutlineUiOptions.FadeIn(0.15f));

h.SetStyle(otherStyle, 0.3f);   // плавная смена стиля
h.FadeTo(0.5f, 0.2f);
h.FadeOutAndHide(0.2f);

// временные эффекты
OutlineUiFx.Pulse(icon);
OutlineUiFx.Flash(card, new Color(2f, 2f, 2f, 0.8f));
OutlineUiFx.DissolveOut(panel, 0.8f, onComplete: () => Debug.Log("растворён"));
OutlineUiFx.DissolveIn(panel);
```

Разметка — контейнер `OutlineUiTarget`: всё внутри подсвечивается, пока он на панели и `highlighted` включено.

```xml
<Exerussus.Outline.UI.OutlineUiTarget outline-style="project://database/Assets/.../Style_Selected.asset" fade-in="0.15">
    <ui:Button text="Играть" />
</Exerussus.Outline.UI.OutlineUiTarget>
```

### OutlineUi

| Метод | Что делает |
|---|---|
| `Show(element, style, options)` | Подсветка элемента → `OutlineUiHandle`. Несколько подсветок одного элемента накладываются по порядку. |
| `SetStyle(h, style, duration)` | Сменить стиль сразу или плавно: цвета, ширины, кривые, градиенты и эффекты смешиваются, тип паттерна переключается на середине. |
| `SetFade`, `FadeTo`, `FadeOutAndHide`, `Hide` | Непрозрачность и снятие. |
| `HideAll(element)`, `HideAll()` | Снять подсветки элемента / все. |

Свои фильтры элемента (`style.filter`, заданные в коде) сохраняются: подсветки добавляются после них и снимаются, возвращая исходный список.

## Стиль (OutlineUiStyle)

Свой ассет стиля — `OutlineUiStyle` (Create → Exerussus → OutlineUI → Style), отдельно от `OutlineStyle` мира: в интерфейсе нет перекрытия сценой, поверхности объекта, прозрачности и мировых единиц, а привычные ширины — единицы пунктов, а не десятки пикселей.

- Все длины — в **пунктах** UI (масштаб панели применяется сам): ширины свечения и контура, период паттерна, шум, огонь, электричество, искры, волны, сканер, растворение, тайл текстуры заливки.
- Паттерн, сканер, растворение и текстура заливки — в пространстве элемента: едут вместе с ним.
- Состав: свечение с кривой и пульсом, внутренний контур, заливка с текстурой, паттерны на любом слое (включая свою текстуру), градиенты по ширине и по контуру, волны, бег по контуру, огонь, электричество, искры, сканер, растворение (в том числе по fade), шум, аддитивность.
- Кривые и градиенты по умолчанию — те же, что у `OutlineStyle`.

## Как это работает

Фильтр UI Toolkit растеризует поддерево элемента во временную текстуру и прогоняет проходы:

1. **По строке** (только если у стиля есть свечение; цель шире элемента на дальность свечения). Внутри силуэта (альфа > 0) остаётся исходный цвет; снаружи — расстояние по строке до ближайшего пикселя силуэта с поправкой на его покрытие.
2. **Сборка.** Снаружи — точное евклидово расстояние (минимум по столбцу из √(dx² + dy²)) и свечение с эффектами; внутри — контент, поверх него заливка, внутренний контур (короткий поиск края), паттерны, сканер; растворение режет и контент, и подсветку.

Стиль без свечения (заливка, внутренний контур, вспышка, растворение) — один проход сборки без полей.

Расстояние между проходами хранится в самой текстуре фильтра, формат которой зависит от проекта (sRGB или линейная, 8 бит): метка — в RGB только значениями 0 и 1 (они не меняются при sRGB-преобразованиях), значение — в альфе (она не гамма-кодируется). Premultiplied-контент не может иметь канал 1 при альфе < 1, поэтому метка не путается с содержимым.

Цена: у UI Toolkit постоянная часть на каждый элемент с фильтром (растеризация поддерева во временную текстуру) — на Intel UHD ~0.14 мс на элемент; поле добавляет ~2R выборок на пиксель поля (R — дальность свечения в пикселях), дальность ограничена 128 px. Для UI держите свечение в пределах 2–16 пт.

Параметры стиля ставятся в свойства прохода колбэком `applySettingsCallback` (время, стиль слота, плавная смена, fade). Анимированные стили перерисовываются каждый кадр (`MarkDirtyRepaint`), статичные — только при изменении.

## Ограничения

- Цепочка фильтра не видит исходник после первого прохода, поэтому снаружи силуэта в текстуре хранится не цвет, а расстояние: полупрозрачное «облако» вокруг содержимого (альфа < 1/500) считается пустотой.
- Подсветка рисуется в пределах фильтра элемента: если родитель обрезает содержимое (`overflow: hidden`), свечение обрезается тоже — оставляйте место (margin) вокруг.
- Группы (общий силуэт соседних элементов) — подсветкой общего родителя.
- Не больше 127 подсветок UI одновременно.
