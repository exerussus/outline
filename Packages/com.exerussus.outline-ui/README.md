# Exerussus Outline UI

Подсветка элементов UI Toolkit теми же стилями `OutlineStyle`, что и подсветка объектов мира (`com.exerussus.outline`). Контур строится по реальной альфе содержимого: текст, картинки с прозрачностью, скругления, бордеры, дочерние элементы — без ручных масок.

## Требования

- Unity 6000.6 (фильтры UI Toolkit: `FilterFunctionDefinition`, `style.filter`).
- `com.exerussus.outline` 0.4.0 — стили и часы.

## Использование

```csharp
using Exerussus.Outline.UI;

// подсветить элемент (вместе с детьми)
var h = OutlineUi.Show(button, style, OutlineUiOptions.FadeIn(0.15f));

h.SetStyle(otherStyle, 0.3f);   // плавная смена стиля
h.FadeTo(0.5f, 0.2f);
h.FadeOutAndHide(0.2f);

// временные эффекты
OutlineUiFx.Pulse(icon);
OutlineUiFx.Flash(card, new Color(2f, 2f, 2f, 0.8f));
OutlineUiFx.DissolveOut(panel, 0.8f, onComplete: () => Debug.Log("растворён"));
OutlineUiFx.DissolveIn(panel);
```

Разметка — контейнер `OutlineUiTarget`: всё внутри подсвечивается, пока он на панели и `highlighted` включено.

```xml
<Exerussus.Outline.UI.OutlineUiTarget outline-style="project://database/Assets/.../Style_Selected.asset" fade-in="0.15">
    <ui:Button text="Играть" />
</Exerussus.Outline.UI.OutlineUiTarget>
```

### OutlineUi

| Метод | Что делает |
|---|---|
| `Show(element, style, options)` | Подсветка элемента → `OutlineUiHandle`. Несколько подсветок одного элемента накладываются по порядку. |
| `SetStyle(h, style, duration)` | Сменить стиль сразу или плавно: цвета, ширины, кривые, градиенты и эффекты смешиваются, тип паттерна переключается на середине. |
| `SetFade`, `FadeTo`, `FadeOutAndHide`, `Hide` | Непрозрачность и снятие. |
| `HideAll(element)`, `HideAll()` | Снять подсветки элемента / все. |

Свои фильтры элемента (`style.filter`, заданные в коде) сохраняются: подсветки добавляются после них и снимаются, возвращая исходный список.

## Стили в UI

- Ширины (`outerWidth`, `innerWidth`), масштаб паттерна (`patternScale`), шума, огня, электричества, искр, волн — в **пунктах** UI (множитель масштаба панели применяется сам).
- `patternSpace`: `Screen` — паттерн в пунктах элемента (едет вместе с элементом); остальные — в «мировых» единицах, 1 единица = 100 пунктов (`patternWorldScale`, `dissolveScale`, `scanPeriod`, тайл текстуры заливки).
- Работают: свечение с кривой и пульсом, внутренний контур, заливка с текстурой, паттерны на любом слое (включая свою текстуру), градиенты по ширине и по контуру, волны, бег по контуру, огонь, электричество, искры, сканер, растворение, шум, аддитивность, fade.
- Не применяются (смысла в UI нет): перекрытие сценой, rim, прозрачность и маскировка, `widthMode = World`.

## Как это работает

Фильтр UI Toolkit растеризует поддерево элемента во временную текстуру с полями на дальность свечения и прогоняет цепочку проходов:

1. **Сиды.** Внутри силуэта (альфа > 0) остаётся исходный цвет; снаружи RGB свободны — туда пишется «сида нет».
2. **Шаги JFA** (N по дальности: 3, 5, 7 или 9 шагов, плюс контрольный шаг 1). Снаружи силуэта в RGB — смещение до ближайшего пикселя силуэта (12 + 12 бит), внутри — нетронутый контент.
3. **Сборка.** Внутри — контент, поверх него заливка, внутренний контур (короткий поиск края), паттерны, сканер; снаружи — свечение по расстоянию до края с эффектами; растворение режет и контент, и подсветку.

Параметры стиля ставятся в свойства прохода колбэком `applySettingsCallback` (время, стиль слота, плавная смена, fade). Анимированные стили перерисовываются каждый кадр (`MarkDirtyRepaint`), статичные — только при изменении.

## Ограничения

- Цепочка фильтра не видит исходник после первого прохода, поэтому снаружи силуэта в текстуре хранится не цвет, а смещение: полупрозрачное «облако» вокруг содержимого (альфа < 1/500) считается пустотой.
- Подсветка рисуется в пределах фильтра элемента: если родитель обрезает содержимое (`overflow: hidden`), свечение обрезается тоже — оставляйте место (margin) вокруг.
- Группы (общий силуэт соседних элементов) — подсветкой общего родителя.
- Не больше 127 подсветок UI одновременно.
