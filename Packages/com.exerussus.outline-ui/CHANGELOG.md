# Changelog

## 0.2.0

- Время слота: у каждой подсветки свои часы. `SetFrozen` / `SetFrozenWithin(root)` — заморозить анимацию без снятия подсветки (облик как в момент заморозки, разморозка продолжает с того же места).
- `SetSuspended` / `SetSuspendedWithin(root)` — снять фильтр с элемента, сохранив хэндл и состояние; возобновление возвращает фильтр. Под уровни детализации: «не в фокусе» → заморозка, «далеко» → пауза.
- `FadeOutAndHide` у замороженной или приостановленной подсветки снимает её сразу.
- Приоритет подсветки `OutlineUiOptions.priority` (`Priority(n)`, `WithPriority(n)`): при переполнении слотов новая вытесняет самую неважную с приоритетом ниже; если таких нет — как раньше, предупреждение и `Invalid`.
- `OutlineUiFx.Flash(element, OutlineUiStyle, …)` — вспышка готовым стилем, без создания временного.
- `OutlineUiTarget`: стили состояний `hover-style`, `pressed-style`, `selected-style`, флаг `selected`, `priority`. Порядок: нажат → наведён → выбран → базовый.
- `OutlineUiHandle`: `SetFrozen`, `SetSuspended`, `IsFrozen`, `IsSuspended`.

## 0.1.0

- Подсветка элементов UI Toolkit фильтром по реальной альфе содержимого: `OutlineUi.Show` → `OutlineUiHandle` (fade, плавная смена стиля, снятие), несколько подсветок на элемент, пользовательские фильтры элемента сохраняются.
- Поле расстояний в цепочке проходов фильтра: проход по строке + сборка со столбцом (точное евклидово расстояние); метка в RGB (0/1, устойчиво к sRGB), значение в альфе; внутри силуэта — исходный контент. Стиль без свечения — один проход без полей. Дальность до 128 px.
- Свой стиль `OutlineUiStyle`: все длины в пунктах UI, только применимое в интерфейсе.
- Эффекты стиля: свечение (кривая, пульс, градиенты по ширине и контуру, волны, бег по контуру, огонь, электричество, искры), внутренний контур, заливка с текстурой, паттерны, сканер, растворение, шум, аддитивность.
- `OutlineUiFx`: `Pulse`, `Flash`, `DissolveOut`, `DissolveIn`, `Restore`, `IsDissolved`.
- `[UxmlElement] OutlineUiTarget` — подсветка из разметки.
