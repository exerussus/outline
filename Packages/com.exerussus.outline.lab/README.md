# Exerussus Outline Lab

Площадка для `com.exerussus.outline`: тестовая сцена, пресеты стилей, управление мышью, HUD и бенчмарк.

## Меню

- **Exerussus → Outline → Lab → Собрать сцену OutlineLab** — подключает фичу к рендерерам URP, создаёт стили, материалы, текстуры и сцену в `Assets/OutlineLab`.
- **Exerussus → Outline → Lab → Сбросить стили к пресетам** — возвращает стили в `Assets/OutlineLab/Generated` к исходным значениям.

## Сцена

- Тестовые объекты: куб с жёсткими рёбрами, тонкие цилиндры, пересекающиеся объекты разных групп, объекты за стеной, решётка с альфа-клипом, капсулы на разной глубине (ширина в мире).
- Ряд-витрина пресетов: Neon, Toon, Warning, Hatched, Hologram, Halftone, HexShield, Marching.
- Второй ряд — эффекты: Fire, Electric, Sonar, Rainbow, Sparkle, Scanner, Dissolve, Textured, Cloak, Glass.
- Глобальный Volume с Bloom.

Управление в Play:

| Ввод | Действие |
|---|---|
| Наведение | Стиль Hover |
| ЛКМ | Выделить / снять (Selected, группа 1) |
| ПКМ | Враг / снять (Enemy, группа 2) |
| Backspace | Снять всё |
| 0–3 | Отладочный вид: кадр, маска, сиды, поле |
| P | Перебор паттернов стиля Selected |
| O | Пространство паттерна Selected: экран, объект, поверхность объекта, поверхность мира |
| C | Кроп вкл/выкл |
| A | Сглаживание края: выкл, ×2, ×4, ×8 |
| V | Камера: общий план / второй ряд с эффектами |
| X / G / F | Объект под курсором: растворить или проявить / пульс / вспышка |
| T | Плавно сменить стиль всех выделенных (выделение ↔ враг) |

Панель UI в правом нижнем углу (пакет `com.exerussus.outline-ui`): кнопка, иконка с альфой, текст, скруглённая карточка. Наведение — стиль Hover; ЛКМ — следующий стиль по кругу с плавным переходом (Selected, Enemy, Neon, Fire, Electric, Rainbow, Sparkle, Scanner, Hatched, Textured, затем снять); ПКМ — растворить или проявить; колесо — пульс. После обновления пакета пересоберите сцену площадки — сборщик проставит стили и иконку HUD.

Изменения ассетов, сделанные клавишами, возвращаются при выходе из Play.

## Бенчмарк UI (outline-ui)

Меню **Exerussus/OutlineUI/Lab/Собрать сцену бенчмарка** — сцена `Assets/OutlineUiLab/OutlineUiLab.unity` (UIDocument, PanelSettings с постоянным размером пикселя, `OutlineUiBenchmark` со стилями площадки). **Exerussus/OutlineUI/Lab/Запустить бенчмарк** — открыть сцену и войти в Play (соберёт, если её нет).

Прогон: ярусы 1 / 10 / 50 элементов (кнопки, иконки с альфой, текст, скруглённые карточки). На каждом ярусе — база без подсветки, все стили (кроме прозрачности и маскировки), временные эффекты (пульс, вспышка, растворение, появление), смена стиля Selected ↔ Enemy; на первом и последнем — разложение: пустой фильтр, ширины 4 / 16 / 60 / 200 пт (разное число шагов JFA), только внутренний контур. В конце — движение одного элемента (сдвиг, масштаб, наклон) со снимком в крайней точке `_a`. Лог — `Temp/outline-ui.log` (сводка «стиль × ярус», дрейф базы), снимки — `Temp/OutlineUiShots/UNNN_xK_имя.png`.

## Бенчмарк

Компонент `OutlineBenchmark` на объекте HUD. При запуске Play он по очереди прогоняет режимы:
- фича выключена;
- настройки проекта;
- авто-масштаб;
- фиксированные масштабы ×1, ×0.75, ×0.5, ×0.25;
- ×1 с JFA+1;
- авто без мягкого стыка, без scissor, без кропа;
- авто без сглаживания края, со сглаживанием ×2 и ×8;
- снова фича выключена;
- визуальные режимы без замера: ×1 без сглаживания, ×4, ×8, отладочные виды маски, сидов и поля;
- витрина: камера переезжает на отдельную площадку, подсветки сцены снимаются. Все пресеты, типы паттернов и временные эффекты (растворение, появление, пульс, вспышка) по очереди накладываются на три яруса: 1 куб крупным планом, 3 разные фигуры, 21 фигура (каждый объект — своя подсветка). Для каждого сочетания — замер к кадру своего яруса без подсветки и снимок `SNNN_xK_имя.png`; в конце лога — сводка «стиль × ярус». На первом ярусе ещё разложение постоянной цены. На каждом ярусе — «смена стиля Selected ↔ Enemy» (каждую секунду, переход 0.5 с). На первом и последнем ярусах — разложение цены координат поверхности (`surfaceDiag`: эталон в `Object`, полная, без чтения, без записи, прежний путь через MSAA-цель; два круга, плюс без сглаживания), в конце лога — таблица «чтение / запись / прочее / прежний путь». Последний этап — «движение»: куб вращается и ездит влево-вправо (`showcaseMotionAmplitude`, `showcaseMotionPeriod`); заливка текстурой и паттерн Hex в каждом пространстве (`Screen`, `Object`, `SurfaceObject`, `SurfaceWorld`) и пресеты с поверхностью или текстурой. Снимки в крайних точках (`_a`, `_b`) и в центре; в сводку этап не входит, база у него своя. Прогон витрины — около 6 минут.

После замера каждого режима с фичей и в каждом визуальном режиме сохраняется снимок кадра: в редакторе — `<проект>/Temp/OutlineShots/NN_имя.png`, в билде — `persistentDataPath/OutlineShots`. Старые снимки удаляются при запуске, HUD на снимках скрыт. Отключается полем `captureScreenshots`.

На каждый режим — 1 с прогрева и 4 с замера, VSync на это время выключен. После прогона бенчмарк восстанавливает настройки и выходит из Play.

В лог пишутся:
- время кадра (среднее и p95) и прирост к среднему двух замеров без фичи;
- время записи на CPU;
- масштаб и размер поля, кроп, число проходов, стоимость и бюджет;
- в конце — дрейф между первым и последним замером без фичи.

Лог перезаписывается после каждого режима:
- в редакторе — `<проект>/Temp/outline.log` (Temp очищается при закрытии редактора);
- в билде — `persistentDataPath/outline.log`;
- в WebGL — только консоль, весь лог выводится одним сообщением в конце.

Автозапуск и выход из Play отключаются полями `Run On Start` и `Stop Play On Finish`.
